# Facts worksheet — one value per fact

Every value below is used in three places at once: the visible pages, the structured data (schema), and `/llms.txt`, which AI assistants read. Once you confirm a value and enter it in **WordPress → Settings → KMS Facts**, the whole site updates.

**How the defaults were chosen.** Each one is the value used most consistently on the live site, or the one confirmed by an outside source. Anything marked ⚠️ conflicts somewhere on the current site or in a third-party listing, so the client must confirm it.
