Fast, accessible theme for Krishna Music School, built around enrolment in live online Indian music classes.

== Description ==

Pairs with the KMS Core plugin, which provides the classes, prices, reviews, FAQs, enquiry form, structured data and llms.txt. Without the plugin the theme still renders pages and posts.

* Online-first homepage and /online-classes/ hub
* Answer-first class pages with an "At a glance" table, prices in INR with approximate USD/EUR/GBP, hours in the visitor's time zone
* One H1 per page, breadcrumbs, real 404 page
* No page builder, no jQuery; WCAG 2.1 AA

Customise: Appearance → Customize → Krishna Music School (hero, announcement bar, class hub texts).
Facts (prices, phone, hours, retreat dates): Settings → KMS Facts (plugin).
